reRECOIL v1
===========

An unofficial fan-fixed version of Recoil (1999), not affiliated with or
endorsed by the game's rights holders.

The original Recoil CD is required for game media.

Installation
------------
1. Extract the complete 7z archive into a writable folder, keeping all directories.
   Avoid Program Files so the game can save settings and progress.
2. Insert the original Recoil CD and run reRECOIL.exe from the extracted folder.

Keep the supplied DLLs beside reRECOIL.exe; do not copy them into Windows folders.
See RIGHTS.md in this folder for notices.

Distribution and updates: https://github.com/Vorta/reRECOIL-v1/releases
Fan-project website: https://www.playrecoil.com/
