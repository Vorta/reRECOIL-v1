# reRECOIL v1

An unofficial fan-fixed version of **Recoil (1999)**. Not affiliated with or endorsed by the game’s rights holders.

**The original Recoil CD is required for game media.**

1. Download the **`.7z` game archive** from the **[latest release](https://github.com/Vorta/reRECOIL-v1/releases/latest)**. Ignore the “Source code” downloads.
2. Extract all files into a writable folder, keeping the folder structure intact.
3. Insert the original CD and double-click **`reRECOIL.exe`** in the extracted folder.
